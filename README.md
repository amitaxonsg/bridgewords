# BridgeWords Consulting website

Modern static rebuild of https://bridgewords.sg/ for GitHub Pages.

## Goals

- Preserve the existing BridgeWords information architecture and established page URLs.
- Keep the BridgeWords identity while modernising presentation and typography.
- Responsive, mobile-first HTML/CSS with minimal JavaScript.
- Google-hosted Manrope font with system fallbacks.
- SEO: unique titles/descriptions, canonical URLs, robots directives and XML sitemap.
- AEO/GEO: clear question-and-answer content, semantic headings and concise entity/service language.
- Structured data: Schema.org ProfessionalService JSON-LD on all pages.
- AI discovery: llms.txt plus explicit public crawler guidance in robots.txt.
